# Images folder

Drop image files here (on GitHub: Add file -> Upload files, into `public/images/`).

Supported: .jpg, .jpeg, .png, .webp

Once uploaded, each file is served from the site root at:

  /images/<your-file-name>.jpg

Example: uploading `mulch-bed.jpg` makes it available at `/images/mulch-bed.jpg`
and you can use it anywhere in the site as:

  <img src="/images/mulch-bed.jpg" alt="Fresh mulch bed" />

Tips:
- Use lowercase file names with dashes, no spaces (e.g. `tree-removal-front-yard.jpg`).
- Keep files under ~2 MB each so pages load fast.
- After uploading, tell me the file names and I'll add them to the Gallery carousel.
